Spesifikasi Lengkap Aplikasi Manajemen Pembayaran Kosan
1. OVERVIEW SISTEM
1.1 Deskripsi Aplikasi
Aplikasi web untuk manajemen pembayaran kosan yang memfasilitasi transaksi antara penghuni dan pengelola, dilengkapi sistem pelaporan dan monitoring keterlambatan pembayaran.
1.2 Tech Stack

Backend: Laravel 12.x
Frontend: React 18.x
Database: MySQL 8.0+
Cache: Redis 7.x
Deployment: cPanel
Web Server: Apache/LiteSpeed (cPanel default)


## 4. FITUR & FUNCTIONAL REQUIREMENTS

### 4.1 Autentikasi & Otorisasi
- **Login/Logout** menggunakan Laravel Sanctum
- **Role-based Access Control (RBAC)**:
  - **Admin**: Full access
  - **Pengelola**: Manage tenants, verify payments, view reports
  - **Penghuni**: Submit payments, view payment history
- **Password Reset** via email
- **Email Verification**

### 4.2 Manajemen User
- CRUD user (Admin only)
- Profile management
- Change password
- Activity logging

### 4.3 Manajemen Kamar
- CRUD kamar kosan
- Set harga sewa per bulan
- Status kamar (tersedia/terisi/maintenance)
- Upload foto kamar (optional)

### 4.4 Manajemen Penghuni
- Registrasi penghuni baru
- Assignment kamar
- Upload KTP/identitas
- Data kontak darurat
- Deposit management
- History perpindahan kamar
- Terminate tenant

### 4.5 Pembayaran

#### 4.5.1 Submit Pembayaran (Penghuni)
- Form input pembayaran:
  - Bulan pembayaran
  - Metode pembayaran
  - Bank tujuan
  - Upload bukti transfer (screenshot)
- Auto-generate kode pembayaran
- Notifikasi submit berhasil

#### 4.5.2 Verifikasi Pembayaran (Pengelola)
- List pembayaran pending
- Preview bukti transfer
- Approve/Reject pembayaran
- Input alasan penolakan
- Notifikasi ke penghuni

#### 4.5.3 Kalkulasi Denda
- Auto-calculate denda keterlambatan
- Konfigurasi denda per hari/tetap
- Display total pembayaran + denda

### 4.6 Laporan

#### 4.6.1 Laporan Pembayaran
- Filter by:
  - Periode (bulan/tahun)
  - Status pembayaran
  - Kamar/Penghuni
- Export ke Excel/PDF
- Summary:
  - Total pembayaran masuk
  - Total denda
  - Pembayaran pending

#### 4.6.2 Laporan Keterlambatan
- List penghuni telat bayar
- Jumlah hari keterlambatan
- Total denda
- History keterlambatan per penghuni
- Export laporan

#### 4.6.3 Laporan Keuangan
- Income per bulan
- Occupancy rate
- Projection income
- Outstanding payments

### 4.7 Dashboard

#### 4.7.1 Dashboard Pengelola
- Summary cards:
  - Total penghuni aktif
  - Pembayaran bulan ini
  - Pending verification
  - Overdue payments
- Chart: Trend pembayaran 6 bulan terakhir
- List terbaru: Recent payments, late payments

#### 4.7.2 Dashboard Penghuni
- Status pembayaran bulan ini
- History pembayaran
- Upcoming due date
- Quick submit payment

### 4.8 Notifikasi & Reminder
- Email reminder H-7 sebelum jatuh tempo
- Email reminder H-0 (hari jatuh tempo)
- Email reminder keterlambatan (H+3, H+7)
- In-app notification
- WhatsApp notification (optional - integration)

### 4.9 Pengaturan Sistem
- Konfigurasi tanggal jatuh tempo
- Konfigurasi denda keterlambatan
- Konfigurasi email templates
- Backup & restore

5.2.4 Scheduled Tasks (Console/Kernel.php)
phpprotected function schedule(Schedule $schedule)
{
    // Check overdue setiap hari jam 00:01
    $schedule->command('payments:check-overdue')
             ->dailyAt('00:01');
    
    // Kirim reminder H-7 setiap hari jam 08:00
    $schedule->command('payments:send-reminders')
             ->dailyAt('08:00');
}
